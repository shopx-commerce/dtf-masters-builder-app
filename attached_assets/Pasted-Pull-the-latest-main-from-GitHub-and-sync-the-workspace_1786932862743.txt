What changed, so you can sanity-check the running app rather than just the build:

1. The printed name label now applies to every copy of a design. Copies made from
   a layers row used to be created with the flag cleared, so copies added after
   turning the label on printed without a name. The row toggle also now covers
   copies at other sizes, not just the row it was pressed in.
2. Adding or removing copies now packs the sheet with the same options the
   Auto-Arrange button uses, so pressing the button after a copy click no longer
   finds a tighter layout. Measured as costing no extra film and no extra time.
3. The preview is covered by a fading veil while the sheet is being packed or
   grown, so the customer no longer watches copies land in the wrong place and
   jump. It takes no pointer events and sits under the mobile tool/layers sheets,
   so repeated "+" clicks must still work while it is up.
