Auto Arrange Button — Color, Style & Location
Color scheme: Teal/cyan — text-[#0891B2] (Tailwind cyan-600) on a light slate background bg-[#F1F5F9] with a slate border border-[#CBD5E1]. This is the same base style as other action buttons but uses cyan text instead of blue (Clean Alpha = blue text-[#2563EB], Duplicate = purple text-[#7C3AED], Auto Arrange = teal text-[#0891B2]).

Active vs disabled:

// Active (2+ designs exist):
'bg-[#F1F5F9] hover:bg-[#E2E8F0] text-[#0891B2] border border-[#CBD5E1] shadow-none'
// Disabled (fewer than 2 designs):
'bg-gray-200 text-gray-500 opacity-30 pointer-events-none'

Icon: <LayoutGrid className="w-3 h-3 lg:w-4 lg:h-4 flex-shrink-0" /> from lucide-react

Location — Mobile toolbar (Row 1), pinned to the far right:

<button
  onClick={() => { handleAutoArrange({ preserveSelection: selectedDesignIds.size >= 2 }); setMobilePanel("preview"); }}
  disabled={designs.length < 2 && selectedDesignIds.size < 2}
  className={`flex items-center gap-1 px-2 py-1 rounded-md text-[11px] font-medium min-h-[36px] ml-auto ${
    designs.length >= 2 || selectedDesignIds.size >= 2
      ? 'bg-[#F1F5F9] text-[#0891B2] border border-[#CBD5E1]'
      : 'bg-gray-200 text-gray-500 opacity-30 pointer-events-none'
  }`}
  title={t("editor.autoArrangeAll")}
>
  <LayoutGrid className="w-3 h-3" />
  {t("editor.autoArrange")}
</button>

Sits at the end of the Undo / Redo / Delete icon cluster — ml-auto pushes it to the far right of the row. It's in the same div as those three icon-only buttons.

Location — Desktop toolbar (Row 1), also far right — but only shown on mobile via isMobile flag:

{isMobile && (
  <button
    ...responsive classes with lg:px-4 lg:py-2 lg:text-sm...
    className={`... ml-auto ${
      designs.length >= 2 || selectedDesignIds.size >= 2
        ? 'bg-[#F1F5F9] hover:bg-[#E2E8F0] text-[#0891B2] border border-[#CBD5E1] shadow-none'
        : 'bg-gray-200 text-gray-500 opacity-30 pointer-events-none'
    }`}
  >
    <LayoutGrid className="w-3 h-3 lg:w-4 lg:h-4 flex-shrink-0" />
    {t("editor.autoArrange")}
  </button>
)}

Location — Desktop toolbar (Row 2), after Duplicate+Arrange button — ml-auto on the container:

There's also a second Auto Arrange button in Row 2 of the desktop toolbar, inside {activeImageInfo && ...}, right-aligned via ml-auto on its wrapping div, sitting after the Duplicate count input and "Dup+Arrange" button:

<div className="flex items-center gap-1 ml-auto">
  {/* Duplicate button */}
  {/* Count input */}
  {/* Dup+Arrange button */}
  {/* Auto Arrange button here — same color/style */}
</div>

Enabled condition: designs.length >= 2 || selectedDesignIds.size >= 2 — needs at least 2 designs total, OR 2+ selected. When 2+ are selected, it only rearranges the selection; otherwise it rearranges everything.
